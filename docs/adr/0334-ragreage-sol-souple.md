# ADR 0334 — Ragréage sous sol souple (F-159, lot 6)

- Statut : accepté (15/11/2026)
- Fonctionnalité : F-159, lot 6 ; dernier point des corrections de l'essai réel

## Constat

Le plan de l'essai écrit « ragréage sur dalle BA créée, revêtement de sol souple » dans quatre
pièces. Le DPGF chiffrait le sol souple (lot du peintre) mais aucun ragréage : le carreleur n'en
compte que sous le carrelage.

## Décision

- Le lot du peintre gagne « Ragréage sous sol souple », sur la surface des pièces en sol souple,
  juste avant le poste « Sol souple » (même calcul, même origine, totaux partiels compris).
- C'est un poste de convention : il cède la place à un ragréage écrit sur le plan dans ce lot
  (ADR 0332).

## Conséquences

- Un sol souple n'est plus chiffré sans son support. Le lot reste celui du sol souple ; l'artisan
  déplace le poste dans le DPGF s'il le confie à un autre corps de métier.
